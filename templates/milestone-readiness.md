# Milestone readiness review — {{project}} / {{milestone}}

Run this **ten working days out**, not the day before. The point is to find the
slip while there is still time to do something other than announce it.

## 1. Scope
- [ ] The list is frozen and written down somewhere both art and design can see
- [ ] Every item has an owner and an estimate
- [ ] Items added since the last review are listed separately, with what was cut to pay for them

## 2. Capacity
- [ ] Leave in the window is on the schedule (Leave view, coverage flags clear)
- [ ] Nobody critical is the only person who can do their part
- [ ] Estimated days ≤ available days, with the shortfall named if not

## 3. Quality bar
- [ ] Acceptance criteria written, not assumed
- [ ] Review slots booked in the calendar, with named reviewers
- [ ] Known art bugs triaged: fix / accept / defer, each decided by a person

## 4. Dependencies
- [ ] Audio, code, design and localisation deliveries confirmed with dates
- [ ] Outsourcing batches have a delivery date and an inspection slot
- [ ] Build/pipeline changes landing in the window are known

## 5. The honest question
> If this had to ship on the date with what exists today, what would we cut,
> and who has agreed to that in advance?

**Verdict:** Green / Amber / Red — and the one thing that would change it.
