# Templates

Blank starting points, kept deliberately plain so they survive being pasted
into Word, Confluence, a Teams message or a SharePoint page.

| File | Use |
|---|---|
| `team-roster.csv` | Import your real team in **Team → Import**. Allocation is `CODE:percent`, skills are `Skill:level` (1–5). |
| `leave-import.csv` | Bulk leave in **Leave → Import**. Also accepts a tab-separated paste straight from a spreadsheet. |
| `tasks-import.csv` | Bulk tasks in **Tasks → Import**. |
| `budget-lines.csv` | The shape the Finance CSV export uses, for round-tripping through Excel. |
| `1to1-agenda.md` | A 1:1 that is theirs, not a status update. |
| `milestone-readiness.md` | Run ten working days before a milestone, not the day before. |
| `outsourcing-brief.md` | What a vendor needs to deliver something acceptable first time. |
| `monthly-art-status.md` | One page of status that a producer will actually read. |

The Markdown ones are worth uploading to your project SharePoint folder — once
Microsoft 365 is connected, you can edit them straight from the **Files** view.
